# MathCraft платформасы

MathCraft: математикалық сауаттылықты дамытуға арналған оқу-әдістемелік платформа.
5-сынып оқушыларына арналған факультативтік курс (34 сағат). Платформа дайын
[MathCraft ойынын](https://eduvisionkz.github.io/mathcraft/) өзгеріссіз, тек
сілтеме/iframe арқылы біріктіреді.

## Құрылым

```
/
├── index.html                  — жалғыз HTML бет (беттер арасын hash арқылы ауыстырады)
├── assets/
│   ├── images/, icons/         — суреттер мен иконкалар үшін (бос, толтыруға дайын)
│   └── documents/
│       ├── mathcraft-ktzh.docx / .pdf
│       ├── mathcraft-34-kmz.docx / .pdf
│       └── mathcraft-zhumys-dapteri.docx / .pdf
├── css/
│   ├── base.css                — түстер, типографика, негізгі компоненттер
│   └── platform.css            — мәзір, кестелер, парақшалар, ойын блогы
├── js/
│   ├── app.js                  — iframe fallback логикасы, соңғы бетті есте сақтау
│   ├── navigation.js           — беттер арасын ауыстыру (hash негізінде)
│   └── documents.js            — JSON деректерін жүктеу, КТЖ/ҚМЖ/дәптер рендерингі
├── data/
│   ├── curriculum.json         — 34 миссияның бірыңғай дерегі (КТЖ мен ҚМЖ осыдан оқылады)
│   └── documents.json          — құжат жолдарының конфигурациясы
└── README.md
```

Авторлық бағдарламаның толық Word/PDF нұсқасы, жауаптар жинағы, бағалау
материалдары және апробация/диагностика материалдары сайтқа **жүктелмеген** —
тек «Бағдарлама туралы» бетінде қысқаша сипаттама берілген.

## GitHub Pages-қа жариялау

1. Осы бумадағы файлдарды жаңа немесе бар репозиторийге көшіріңіз.
2. Репозиторийді GitHub-қа жүктеңіз (`git init`, `git add .`, `git commit`, `git push`).
3. GitHub репозиторийінде **Settings → Pages** бөліміне өтіңіз.
4. **Source** ретінде `main` тармағын (branch) және `/ (root)` бумасын таңдаңыз.
5. Бірнеше минуттан кейін сайт мына түрдегі мекенжайда қолжетімді болады:
   `https://<пайдаланушы-аты>.github.io/<репозиторий-аты>/`

Сервер немесе дерекқор қажет емес — платформа толығымен статикалық.

- [x] Барлық 6 мәзір бөлімі ашылады (Басты бет, Бағдарлама туралы, КТЖ, ҚМЖ, Жұмыс дәптері, Ойын)
- [x] КТЖ кестесі 34 тақырыпты көрсетеді, миссия коды/тақырып бойынша іздеу және әлем бойынша сүзгі жұмыс істейді
- [x] КТЖ Word/PDF жүктеу батырмалары (файл болмаса — «Құжат әзірленуде»)
- [x] ҚМЖ парақшалары барлық MC-01–MC-34 үшін жасалды, ҚМЖ материалына, дәптерге және ойынға сілтеме береді
- [x] Жұмыс дәптері бөлімінде PDF сайт ішінде көрінеді, Word жүктеу және миссия бойынша шарлау мүмкіндігі бар
- [x] Ойын бөлімінде iframe + жүктелмесе автоматты «Ойынды ашу» батырмасы (2.5 секундтан кейін)
- [x] Барлық сілтемелер MC кодтары арқылы өзара байланысқан (КТЖ ↔ ҚМЖ ↔ Дәптер ↔ Ойын)
- [x] Мобильді, планшет және компьютер экрандарына бейімделген (responsive grid + бүктелмелі мәзір)
- [x] Ойынның өзі (кодтары, миссиялары, дизайны) өзгертілмеген — тек сыртқы сілтеме/iframe
- [x] Авторлық бағдарламаның толық құжаты, жауаптар мен бағалау материалдары сайтқа жүктелмеген

## Ескерту

- `assets/images` және `assets/icons` бумалары әзірге бос — платформаны нақты
  скриншоттармен/логотиппен толтыру үшін дайын.
- Құжат қолжетімділігі `js/documents.js` ішінде `HEAD` сұранысымен тексеріледі;
  локальді `file://` арқылы ашқанда бұл тексеріс жұмыс істемеуі мүмкін — GitHub
  Pages немесе кез келген HTTP серверде дұрыс жұмыс істейді.
